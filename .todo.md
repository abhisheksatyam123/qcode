## Systems

### Goal
Implement SQLite persistent session storage, session management slash commands (/new, /sessions, /session), colored git diffs, and exact opencode tool call observability views.

### Architecture
- **SQLite Database** (`include/ai/tui/db.h`, `src/tui/db.cpp`):
  - Database manager targeting `~/.qcode.db`.
  - Tables: `sessions` (id, title, provider, model, created_at) and `messages` (id, session_id, sender, content, created_at).
  - Persistence lifecycle: loads last session on startup, automatically saves user prompt, tool calls, tool results, and assistant replies.
- **State management** (`include/ai/tui/state.h`):
  - `ChatState` updated with `session_id` (shared_ptr<string>) to track active session persistence.
- **Commands backend** (`src/tui/commands.cpp`):
  - `/new`: Creates a new session UUID, saves it to SQLite, and clears chat logs.
  - `/sessions`: Lists recent sessions with titles and timestamps.
  - `/session <id>`: Switches active session and reloads history.
  - `/theme <name>`: Dynamic color theme switching.
- **Observability views** (`src/tui/tools.cpp`):
  - Outputs formatted tool blocks: `▾ Observability · <tool_name>` and `$ <command>` (bash) or `↳ Spawn Task` (task), with dynamic return output lines.
- **UI Views** (`src/tui/views.cpp`):
  - Left-bordered user/assistant logs, colored git diff files tab scroll feed.
