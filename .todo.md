## Systems

### Goal
Implement TUI visual and workflow enhancements to align qcode's C++ interface and execution logic with the UX and capabilities of opencode.

### 1. Tab Views (Chat, Files, Stats)
- **Chat Tab**: Clean messages, token usage indicator, tool execution inline details.
- **Files Tab**: Left panel lists modified files; right panel previews selected file diff/content.
- **Stats Tab**: Detailed usage stats (prompt/completion tokens, pricing estimation, processing rate).

### 2. Interaction & Usability
- **Selection & Copy**: Enable keyboard-driven selection in the chat bubble history. Copy highlighted text to the system clipboard (integrating with `xclip` / `xsel` or clipboard commands).
- **Tab Focus Navigation**: Support `Tab` key to cycle focus between text input, tab selectors, and the scrollable content panes.

### 3. Workflow & Safety Checks
- **Ask/Permission Prompts**: Implement approval workflow for tool executions (specifically for mutating `bash` commands and `task` subagent spawns).
- **Shell Sanity Checks**: Port opencode's shell safety check patterns (detecting heredoc syntax errors, warning on gitignore bypass, etc.).
