## Systems

### Goal
Port opencode's essential modules (tools, chat, system prompt) into qcode's C++ TUI.

### Architecture
```
include/ai/tui/
  chat.h              run_llm_generation() signature
  commands.h          SlashCommand struct, builtin_slash_commands(), handle_slash_command()
  config.h            get_antigravity_token(), load_providers_from_config()
  state.h             ModelInfo, ProviderInfo, ChatState
  system_prompt.h     SystemPrompt::build_default() (identity + tool contract)
  tools.h             ToolDescriptor, ToolConfig, Tools::build_definitions()
  views.h             Colour palette, render_logo(), render_view()

src/tui/
  main.cpp            Entry: screen, input, slash popup, submit handler
  chat.cpp            LLM generation thread (tool+streaming paths)
  commands.cpp        Slash command dispatch (model, help)
  config.cpp          Provider config loading (ordered_json for insertion order, self-healing OAuth refresh)
  system_prompt.cpp   System prompt builder (opencode _shared/base style)
  tools.cpp           Tool definitions, descriptions, formatting
  views.cpp           UI rendering (logo, home, chat view, slash popup, model selector popup)
```

### Key fixes applied
- **Double-Encoding `/v1`**: Stripped trailing `/v1` from config-loaded URLs.
- **Antigravity `/v1` 404**: Switched to `:generateContent` for non-streaming, `:streamGenerateContent?alt=sse` for streaming.
- **OAuth Expiry**: Added auto-refresh using refresh token + keyring update.
- **Gemini Parser**: Normalized candidates wrapped under a top-level `"response"` key.
- **Popups**: Implemented flat model selector popup & slash command popup.
- **Tab Views**: Implemented Chat, Files (with Git modified files list and preview), and Stats tabs.
- **Selection & Copy**: Added Ctrl+P selection navigation, y/Enter clipboard yank support.
- **Confirm Dialogs**: Thread-safe permission checks for all mutating tool executions (Approve/Deny popup dialog).
- **Heredoc Safety Check**: Validate unclosed heredoc markers in bash commands.
