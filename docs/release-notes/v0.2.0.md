## Breaking change: server binds localhost by default

`qcode serve` now listens on `127.0.0.1` by default (#58). Remote access needs a token:

```sh
QCODE_SERVER_TOKEN=$(openssl rand -hex 24) qcode serve --host 0.0.0.0 --port 9080
```

Starting a non-loopback bind without `QCODE_SERVER_TOKEN` now fails with an error. Every request to a token-protected server must send `Authorization: Bearer <token>`. If you ran `qcode serve --host 0.0.0.0` before, set the token before upgrading. Browser sign-in works on token-protected binds (#60).

## Highlights

- Server security: Host/Origin gate and token enforcement beyond loopback (#58).
- Web UI: mermaid diagrams render through one serial queue (#61, #63), a `?` shortcut help overlay (#56), and an inline favicon (#64).
- Subagents: event-driven subagent panel, and kill reaches the in-flight request (#57).
- Interrupts: cancel stops the lead agent and its subagents within a second.
- Performance: fast paths for Anthropic text deltas, OpenAI Responses text deltas, and Gemini text chunks (#65, #66).

## Install

Linux x86_64 and macOS arm64 tarballs, with `SHA256SUMS`. The Linux binary needs the system OpenSSL and libcurl runtime libraries (`libssl3`, `libcurl4` on Debian/Ubuntu).
