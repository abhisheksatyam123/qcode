# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within `qcode`, please report it privately:

- **Email**: Security issues can be reported via GitHub Security Advisories or sent directly to the repository maintainers.
- **Response Time**: We aim to acknowledge receipt of security reports within 48 hours and provide updates until a resolution is reached.

Please do not disclose security vulnerabilities publicly until a fix has been issued and merged.
